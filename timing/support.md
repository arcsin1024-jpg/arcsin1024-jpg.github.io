## よくある質問 / FAQ

### 対戦相手が見つかりません / I can't find an opponent

しばらく相手が見つからない場合は、自動的にコンピュータとの対戦が始まります。通信環境をご確認のうえ、時間を置いてお試しください。

If no opponent is found for a while, a match against a computer opponent starts automatically. Please check your connection and try again later.

### 「広告削除」を購入したのに広告が表示されます / I purchased "Remove Ads" but still see ads

設定画面の「購入の復元」をお試しください。解決しない場合はメールでご連絡ください。

Try "Restore Purchase" on the settings screen. If the problem persists, please contact us by email.

### データは引き継げますか？ / Can I transfer my data?

アプリ内の引き継ぎコード機能をご利用ください。詳しくはアプリ内の設定画面をご覧ください。

Use the in-app transfer code feature. See the settings screen in the app for details.
